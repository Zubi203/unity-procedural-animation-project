# Procedural Creatures
A Unity tech demo made to practice and showcase procedural animation techniques. The demo can be played on itch.io at this link: https://zubi-dev.itch.io/procedural-creatures

### Project Features
- A procedural spider animation script that simulates insect like locomotion. This script is flexible and can be used to animate any multi-legged model that has 4 or more legs.
- A procedural animation script that simulates semi-realistic serpentine movement.
- A script for humanoid models for dynamic foot placement on slopes.
- A script for humanoid models that turns the head slightly to look at key objects in the scene.
- A procedural animation script for humanoid models that makes them occasionally reach out and touch nearby objects/terrain.
- Generic and easily reusable abstract state machine architecture.
